# XRD-Plotter 科研级 XRD 堆叠交互作图工作台

一键生成期刊级（Nature / Science / JACS / Adv. Mater. 风格）XRD 堆积对比图、晶面指标标注、底部标准 PDF 卡片对齐及学术相图例。

---

## 快速启动方式

### 方式 1：双击一键启动（最推荐）
在文件夹中直接**双击运行 `start.bat`**：
* 程序会自动启动本地后台服务；
* 并在您的系统默认浏览器中自动打开工作台页面：`http://127.0.0.1:5000`。

### 方式 2：命令行启动
打开终端（PowerShell 或 CMD），在当前目录下运行：
```bash
python app.py
```
然后在浏览器访问 `http://127.0.0.1:5000` 即可。

## 核心功能介绍

1. **多格式数据极速上传**：
   * **实测 XRD 数据**：支持拖拽或批量多选上传 `.txt`、`.csv`、`.dat`、`.xy`。自动智能识别两列数据（$2\theta$ 与强度），自动过滤仪器头部注释。
   * **PDF 标准卡片**：支持上传 Jade / PDF-2 导出的标准峰位卡片文本，也支持直接在页面上“手动录入”角度与强度。
2. **多样品纵向堆叠（Stack Plot）**：
   * 自动层级归一化与纵向错开（Offset），避免谱图混杂。
   * 自由拖拽或点击按钮调整各样品的**上下堆叠顺序**。
   * 各样品独立调节**曲线颜色（预设学术纯色）、线宽、样品标签文字及位置（靠右/靠左/自定义）**。
3. **底部 PDF 卡片（棒状图 / Stick Patterns）**：
   * 底部一键对齐标准卡片，支持多张卡片分色叠加。
   * 可调节棒线粗细、最高峰比例高度、卡片标注文字（如 `Cu PDF#04-0836`）及水平位置。
4. **特征峰与晶面指标标注（(hkl) & Academic Markers）**：
   * 彻底摒弃扑克牌等非严肃符号，内置**国际通用学术几何散点**：
     * 实心菱形（$\blacklozenge$）、实心圆点（$\bullet$）、实心正三角（$\blacktriangle$）、实心倒三角（$\blacktriangledown$）、正方形（$\blacksquare$）、五角星（$\star$）、交叉（$\times$）、加号（$+$）、纯晶面无符号。
   * 支持峰顶标注标准圆括号晶面（如 `(112)`、`(204)`、`(400)`），支持**垂直排版**或**水平排版**。
5. **右上角物相图例（Phase Legend）**：
   * 自定义图例项（几何符号 + 化学式/名称如 `MoSe₂`, `CZTSSe` + 对应颜色）。
   * 自由调整单列、双列或三列排布，自由调节摆放位置。
6. **学术级坐标轴与外观**：
   * 经典的 **Origin 四面封闭边框**，刻度朝内（学术标准），自动生成主刻度与次刻度。
   * 标准 **Times New Roman** 字体与公式格式 $2\theta / ^\circ$、$2\theta (\text{degree})$，支持一键快捷输入。
   * 支持 Savitzky-Golay 智能降噪平滑滤波。
7. **学术出版级导出**：
   * **300 DPI PNG**：国内核心 / SCI 论文插入正文通用标准；
   * **600 DPI PNG**：顶刊投稿超清印刷级位图；
   * **SVG 矢量图**：无限放大不失真，可直接在 Adobe Illustrator、CorelDraw 或 PPT 中“取消组合”进行二次细节精修；
   * **PDF 矢量文档**：方便打印或插入 LaTeX 论文。
   * **工程配置 JSON**：可随时导出当前所有调参状态，下次一键载入继续使用。
